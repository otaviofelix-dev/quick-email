# Quick Email

Mini sistema web desenvolvido com Google Apps Script + HTML/CSS.

## Funcionalidades

- Envio de e-mails
- Interface moderna
- Background tecnológico
- Múltiplos destinatários
- Integração com Google Sheets
- Web App público

## Tecnologias

- Google Apps Script
- HTML5
- CSS3
- JavaScript
